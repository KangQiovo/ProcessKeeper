# Process Keeper 1.7.1

## 改动

- 单击应用行、图标或文字展开或折叠详情，仅点击勾选框才选择项目。覆盖现代版与兼容版的全部应用列表，以及平台、可执行文件、进程、自启动、卸载等嵌套项目。勾选主项同时选择已知子项，折叠状态也有效。现有保留、启用功能不变；取消或操作失败会保留原选择。
- 修复勾选**隐藏 Microsoft 应用**后仍显示商店版画图的问题。必须核实系统登记的健康 Microsoft Store/System 包及实际安装路径；不能仅凭同名文件、显示的发行商或复制的 EXE 判断微软身份。
- 更新弹窗按当前包类型及已验证的运行方式默认选择：合包对应合包，分包保持对应系统与架构，安装版优先对应安装包。若缺少匹配附件，要求用户明确选择，不会默默切换。手动切换其他兼容包需额外确认；不兼容或无法验证的附件仍不可安装。
- 侧栏显示正在运行的版本号；关于页在版本后显示适应主题的合包、免安装、安装或兼容类型标签。去掉更新源上方的固定仓库文案，内部官方仓库保持固定。
- 缓存清理增加应用管理目录内闲置的完整更新包、未完成下载与更新准备目录。保留使用中的会话、锁定或无法核实的文件、设置及白名单；不扫描用户任意下载目录。
- 扩充编号 `unins` 文件、本地化名称及厂商变体等卸载程序识别。仍以登记的卸载命令为执行依据，包括合法的 `Setup.exe`、`Update.exe` 卸载入口；名称推断只提供不确定的标签，不会据此猜测执行卸载命令。
- 注册卸载成功后，只清理经核实为空的对应安装目录。要求完整清单、原注册项已移除、无共享归属且目录身份未变化。非空、共享、被替换、链接或无法验证的目录及全部上级目录均保留，不递归删除残留文件。

## 更新及仍存在的限制

继续支持下载进度、暂停、恢复与更换源。**不倒计时自动更新，也不突然退出应用**：仅用户点击更新并确认后才安装。选择安装包后，经过验证和退出交接打开标准安装向导，请确认安装位置并完成向导；取消安装不能算更新完成，也不是静默安装。旧 1.6.x 更新器支持 PK14 合包；PK17 分包需新版更新器或手动下载。

安装目录内使用免安装包更新，仍更新该安装目录并保留原卸载登记；若想要独立的免安装副本，请另外手动下载到其他目录。切换受支持的安装版本还需在安装向导确认。合包即使放入已验证的安装目录，也保持默认更新合包。

软件未签名，UAC 可能显示未知发行商。兼容界面的材质及部分能力与 WinUI 不同。Windows 7、ARM64 仍未经过真实硬件认证；包校验与隔离的原生、x86 界面测试不能代表完整的实机安装、更新验证。安全软件、文件占用及网络异常仍可能中断操作，程序如实报告，不会误判成功。欢迎[提交 Issue](https://github.com/KangQiovo/ProcessKeeper/issues)，附版本类型、系统及复现步骤共同改进。
