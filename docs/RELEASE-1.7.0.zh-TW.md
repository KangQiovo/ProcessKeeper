# Process Keeper 1.7.0

## 選擇免安裝套件

1.7.0 發布**七個套件**：三個免安裝版本、三個對應的附解除安裝程式版本，以及一個免安裝整合包。

| 檔案 | 適用環境 |
| --- | --- |
| `ProcessKeeper-v1.7.0-win7-x86-compat.exe` | 免安裝 \| Win7 SP1 / 8.1 及支援的新系統 x86/x64 \| WPF；需要 .NET Framework 4.6.2 或相容的較新 4.x。 |
| `ProcessKeeper-v1.7.0-win10-x86-x64.exe` | 免安裝 \| Win10/11 x86、x64 \| x64 19041+ 使用 WinUI；內附 WPF 相容介面供 x86 或支援的較早 x64 系統使用。 |
| `ProcessKeeper-v1.7.0-win10-arm64.exe` | 免安裝 \| Win10 19041+ / Win11 ARM64 \| 原生 ARM64 WinUI；x86 引導程式透過模擬執行。 |
| `ProcessKeeper-v1.7.0-win7-x86-compat-setup.exe` | 安裝版 + 解除安裝程式 \| Win7 SP1 / 8.1 及支援新系統 x86/x64。 |
| `ProcessKeeper-v1.7.0-win10-x86-x64-setup.exe` | 安裝版 + 解除安裝程式 \| Win10/11 x86、x64 \| 包含相同的現代與相容路線。 |
| `ProcessKeeper-v1.7.0-win10-arm64-setup.exe` | 安裝版 + 解除安裝程式 \| Win10 19041+ / Win11 ARM64。 |
| `ProcessKeeper-v1.7.0.exe` | 免安裝整合包 \| 包含全部三種執行載荷 \| 下載最大；保留舊更新程式支援的 PK14 格式。 |

原生引導程式相容 x86 / Win7，採靜態 C/C++ 執行階段。Win7 相容包支援 x86、x64；Win10 x86/x64 套件同時內附現代 x64 與相容載荷，x86 使用 WPF，符合條件的 x64 使用 WinUI。ARM64 提供獨立原生 WinUI 套件；整合包包含全部三種路線。三種版本均另有附解除安裝程式的安裝版。缺少元件時提供官方下載或協助網頁，不自動執行安裝。

## 從 1.6.x 升級

**1.6.x 應用內升級請選擇 ProcessKeeper-v1.7.0.exe（整合包）。** 舊更新程式支援 PK14，會安全拒絕 PK17 分包或安裝程式。若要切換較小版本或安裝版，請手動下載對應檔案。1.7.0 起更新符合原套件類型，安裝程式不會交給自動更新助手執行。

執行適合的新 EXE 並確認系統管理員授權。本機白名單設定檔與設定獨立於下載套件保存，會繼續可用；關閉應用前請複核規則。首次安裝仍以**空白本機白名單**開始，七應用社群範本僅在使用者主動取得雲端設定時載入。

## 同一應用合併為可展開的主項目

- 已安裝應用依可執行檔、身分與產品/發行者資訊合併重複登錄與多個版本；原始安裝記錄、位置、主程式/解除安裝標籤及不同元件路徑皆保留可查。
- 啟動項目將同一應用的多個來源放在一個主項目下；每個登錄視圖、排程工作與其他支援入口仍保留精確目標、啟用狀態及獨立管理操作。
- 執行中程式與白名單共用歸屬規則；解除安裝分組正規化版本、架構後綴，同時保留每個獨立的解除安裝登錄。
- 選取主項目會包含已知全部子項，包括折疊內容；部分選取、搜尋與更新保留精確成員，不修改白名單保護或啟用狀態。

未知歸屬或發行者衝突仍獨立顯示。分組僅整理介面，不授權依名稱啟動、關閉、停用或解除安裝；檔名符合與推斷的主程式標籤仍可能有誤。

## 應用更新

所有安裝及免安裝版本在目前 Windows 使用者與工作階段中作為同一個應用協調執行。核實相容性後先比較版本，版本相同時優先原生 WinUI，再使用 WPF；條件相同保留最新啟動者。未被選中的啟動會啟用既有應用；替換時要求正常關閉並等待舊處理程序結束。不相容的套件不會取代正在執行的適合版本。

更新彈窗顯示實際 Markdown 說明與發行附件。1.7.0 以後自動安裝依目前套件類型與架構選擇適用附件。下載進度視窗支援暫停、繼續與切換來源，同次應用執行切換頁面或重新檢查不會遺失下載；不保證關閉應用後恢復。

下載完成後維持待更新；使用者點選更新並重新啟動且確認後才退出，沒有自動倒數。替換檔案與更新桌面捷徑使用驗證後的交接。新應用回報就緒後才移除本次替換的舊套件備份，不清理無關 EXE。缺少摘要、附件不相容與網路錯誤會如實顯示。

## 驗證與待完善內容

目前現代 Windows 主機上的隔離原生 WinUI 與 32 位 WPF 測試已檢查分組，涵蓋英文、簡中、繁中、深淺主題與兩種視窗寬度。唯讀安裝/啟動清單檢查確認保留原始可執行檔路徑與入口身分；這些檢查未關閉使用者程序或修改使用者啟動設定。

**Win7 / 8.1 / 10 與 ARM64 真機或虛擬機器部署仍未驗證。** 交叉編譯與現代主機上的 32 位 CLR 測試無法取代這些環境實測。相容路線仍缺少 WinRT 套件清單/啟動宣告、無介面瀏覽器即時預覽與 x64 AVD 環境還原；ARM64 亦停用該 x64 專用 AVD 讀取器。字型、材質、圖形及舊硬體效能可能不同，正式 UAC、首次快取解包與公開版本升級流程仍待現場驗證。詳見[相容性與限制](COMPATIBILITY.zh-TW.md)。

歡迎提交可重現的 [Issue](https://github.com/KangQiovo/ProcessKeeper/issues/new/choose)，附系統/建置號、架構、主題/DPI、應用版本及去識別步驟。亦歡迎共創[通用雲端設定](CLOUD-PROFILES.zh-TW.md)、翻譯與相容修正；請勿提交個人路徑、憑證、測試套件或含隱私的記錄。

## 安裝與解除安裝

安裝程式以固定 NSIS 3.13 編譯並請求管理員權限，登錄由本專案管理的電腦級程式項目，安裝固定檔名 ProcessKeeper.exe、Uninstall.exe、install.ini，並建立對應捷徑。解除安裝程式只刪除所屬應用檔案、捷徑及登錄；保留設定、歷史與啟動復原備份。README 說明可選的本使用者資料手動清理。Win7、x86 及 ARM64 目標系統的實際安裝與解除安裝仍待驗證。

在**設定 → 關於 → 本機檔案**使用**清理應用快取**，清理已驗證的舊版本快取。保留目前版本、使用中的檔案、下載、白名單設定檔及設定；不遞迴刪除未確認或已修改的目錄。結果顯示實際檔案數、大小及保留的快取組數。
