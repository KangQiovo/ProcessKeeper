# Process Keeper 1.7.1v2

[English](RELEASE-1.7.2.md) | **简体中文** | [繁體中文](RELEASE-1.7.2.zh-TW.md) | [首页](../README.zh-CN.md)

发布名称为 **1.7.1v2**，内部标准版本号为 **1.7.2**，GitHub 标签为 `v1.7.2`。原有 1.7.1 更新器要求标准 SemVer，因此采用这个数字版本，让旧版能够识别更新，同时保持包校验规则。

## 改动

- 自动模式优先通过 GitHub 官方源下载。官方无法完成有效下载时才尝试第三方源；用户明确选择的源仍然有效。版本信息和 SHA-256 校验依据始终来自固定官方仓库。
- 默认在主应用显示下载状态，不弹出独立进度窗口。勾选显示窗口或主动查看时才打开“更新器”；暂停、继续和切换源保留当前下载状态。
- 在主应用已完成的下载进度旁添加原生“更新并重启”按钮，仅通过校验且准备好的下载可用。点击仍需确认并执行安全交接；下载完成不会自动退出或安装。
- 进度窗口标题改为“更新器”，使用由应用书签图标加入下载箭头的独立图标。现代版、兼容版及可信后台更新助手统一使用该图标。
- 关于页把版本名称与实际构建哈希分成两行，哈希可复制并自动换行；左下角版本显示保持原有方式。
- 外观新增可选的原生材质参数：色调不透明度、亮度层不透明度和色调颜色，可即时预览、恢复原生默认，并纳入设置备份。参数只影响背景；云母采样壁纸，不是透视后方窗口。系统透明度、高对比度及材质支持可能限制效果，兼容界面保留参数但不能渲染 WinUI 材质。
- 保留 1.7.1 的列表展开、微软应用过滤、匹配包类型、应用缓存清理及保守的空安装目录清理改进。[上一版改动](RELEASE-1.7.1.zh-CN.md)。

- 在引用项目上方，以相同原生样式添加本项目地址；打开浏览器前仍需确认。

- 修复主窗口首次显示时，Windows Shell 的短暂遮蔽导致过早报恢复失败的问题。仍须实际观察到窗口可见且解除遮蔽才判成功，继续核验进程身份、桌面以及命令行和辅助页面。

## 更新及仍存在的限制

旧版外观设置和备份会迁移到原生默认。含新增外观参数的备份需要本次修订或更高版本；旧版不支持外观格式版本 2。

继续支持下载进度、暂停、恢复与更换源。**不倒计时自动更新，也不突然退出应用**：仅用户点击更新并确认后才安装。选择安装包后，经过验证和退出交接打开标准安装向导，请确认安装位置并完成向导；取消安装不能算更新完成，也不是静默安装。旧 1.6.x 更新器支持 PK14 合包；PK17 分包需新版更新器或手动下载。

安装目录内使用免安装包更新，仍更新该安装目录并保留原卸载登记；若想要独立的免安装副本，请另外手动下载到其他目录。切换受支持的安装版本还需在安装向导确认。合包即使放入已验证的安装目录，也保持默认更新合包。

软件未签名，UAC 可能显示未知发行商。兼容界面的材质及部分能力与 WinUI 不同。Windows 7、ARM64 仍未经过真实硬件认证；包校验与隔离的原生、x86 界面测试不能代表完整的实机安装、更新验证。安全软件、文件占用及网络异常仍可能中断操作，程序如实报告，不会误判成功。欢迎[提交 Issue](https://github.com/KangQiovo/ProcessKeeper/issues)，附版本类型、系统及复现步骤共同改进。
