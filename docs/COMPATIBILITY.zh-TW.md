## 執行路線

| 環境 | 介面 | 需求 |
| --- | --- | --- |
| Windows 10 19041+ x64 / Windows 11 x64 | WinUI 3、.NET 8 | x64 套件內含執行階段 |
| Windows 10 19041+ ARM64 / Windows 11 ARM64 | 原生 ARM64 WinUI 3、.NET 8 | 內含執行階段；x86 啟動器使用 Windows 模擬 |
| Windows 7 SP1 x86/x64、Windows 8.1 x86/x64、較早或 x86 Win10 | x86 WPF / WPF UI | Framework 4.6.2 或適用的較新 4.x |
| 無 SP1 的 Win7、最初版 Win8、XP、Vista、ARM32 | 僅系統需求頁 | 無受支援的管理路線 |

原生引導程式相容 x86 / Win7，採靜態 C/C++ 執行階段。Win7 相容包支援 x86、x64；Win10 x86/x64 套件同時內附現代 x64 與相容載荷，x86 使用 WPF，符合條件的 x64 使用 WinUI。ARM64 提供獨立原生 WinUI 套件；整合包包含全部三種路線。三種版本均另有附解除安裝程式的安裝版。缺少元件時提供官方下載或協助網頁，不自動執行安裝。

此表為實作目標。**本專案尚未在真實裝置或虛擬機器上驗證 Windows 7、8.1、10 或 ARM64 裝置。** 既有 x86 執行測試在現代 Windows 主機進行；未建立最低記憶體、顯示卡或舊 CPU 效能承諾。

ARM64 系統選擇原生 ARM64 現代載荷，不提供 x86 相容介面回退。ARM64 停用僅適用於 x64 的 AVD 環境讀取器。交叉編譯與在 x64 上執行路線測試無法取代 ARM 裝置驗證。

**1.6.x 應用內升級請選擇 ProcessKeeper-v1.7.1.exe（整合包）。** 舊更新程式支援 PK14，會安全拒絕 PK17 分包或安裝程式。若要切換較小版本或安裝版，請手動下載對應檔案。1.7.1 起預設符合已驗證的套件類型與免安裝、安裝方式；切換其他相容版本需確認。安裝套件經明確同意後開啟標準安裝精靈。

## 兩套介面的差異

| 能力 | 現代 | 相容 |
| --- | --- | --- |
| 程序身分、白名單、關閉確認 | 共用核心 | 共用核心，明確適配 BCL/原生 API |
| 傳統安裝軟體、啟動來源 | 權限允許時可用 | 權限允許時可用 |
| WinRT 套件及啟動宣告 | 支援可讀取的部分 | 未實作 |
| 無頭瀏覽器即時預覽 | 支援已驗證的情境 | 未實作 |
| x64 AVD 啟動環境還原 | 支援已驗證的情境 | x86 模式停用；可嘗試還原已有圖形視窗 |
| 雲母/壓克力及動畫 | 系統支援時可設定 | 不透明 WPF 主題，效果可能不同 |
| 規則與設定格式 | 共用 | 共用 |

相容介面為 WPF，**不是在 Win7 執行 WinUI 3**。字型、主題、DPI 取整、圖形加速及捲動可能不同，WPF 可能採軟體繪製。缺少關鍵身分或能力時應安全拒絕，不能默默跳過保護。

部分虛擬機器與通知區域適配也依賴可信的跨架構參數/環境讀取。x86 相容程序無法驗證 x64 目標時會拒絕這些路線；已有視窗還原仍可能可用。

## 已知限制及待驗證情境

- **實際部署：** 正式 UAC 授權/取消、首次受保護 ProgramData 解壓縮、真實公開版本升級，尚未完整驗證使用流程。隔離測試無法取代。
- **未簽章：** Windows 可能顯示未知發行者，未包含正式程式碼簽章憑證。內部雜湊無法認證被任意重寫的 EXE。
- **舊系統網路：** 憑證、TLS 和系統修補程式影響 GitHub 存取；程式不會為繞過失敗停用憑證驗證或更改全機 TLS 設定。
- **系統讀取阻塞：** WMI、COM、服務及檔案讀取可能超過觀察逾時。虛擬機器查詢已限制並行；卡住的提供者可能持續忙碌，直到返回或應用程式退出，並非所有原生呼叫皆可取消。
- **目錄不完整：** 無法讀取的程序、未載入的使用者登錄、特殊可攜軟體及第三方啟動機制可能缺失；啟動項目不能證明它啟動了目前程序。
- **遊戲分組與發行者：** 支援 Steam ACF/VDF、Epic `.item`、Ubisoft 安裝記錄及部分 EA Games 登錄項目；缺失、衝突或不支援的記錄維持獨立，不保證涵蓋全部 EA app 遊戲庫。微軟簽章驗證設有並行、時間及快取上限，無法驗證或仍在等候的應用程式保持可見。
- **啟動修改：** 系統/原則/驅動程式、未知核准格式及缺少可信原啟動類型的服務保持唯讀。損毀備份被拒絕，其餘有效備份仍可檢視。
- **外部軟體適配：** Steam 儲存/同步、真實 AVD 重啟、虛擬機器主控台及通知區域喚起依賴外部軟體；不宣稱已成功重啟使用者真實 AVD，也不保證雲端存檔完成。
- **視窗還原：** 背景程式可能沒有圖形視窗。終端機、短暫輔助視窗及 AVD 內部視窗不算成功，顯示後也可能無法取得焦點。
- **解除安裝：** 僅涵蓋可讀取的傳統解除安裝登錄，不保證完整發現可攜軟體或 Store 應用程式；無訊息操作必須有已登錄原生命令。登錄仍存在時不會回報完成，具自我保護的軟體可能需要廠商專用工具。
- **效能顯示：** 應用內顯示介面回呼幀率、應用記憶體與總實體記憶體；桌面顯示整機 CPU、實體記憶體與觀察到的桌面合成幀率，後者不是遊戲 FPS 或螢幕更新率。無法測量時顯示未知。壓克力可用性及舊顯示卡效能存在差異，見[雜項說明](UTILITIES.zh-TW.md)。
- **設定：** 一般失敗可嘗試還原，突然斷電卻無法保證多檔案的不可分割性；匯入中斷後請檢查備份。
- **更新：** 沒有發行版或官方 SHA-256 時不自動安裝。第三方入口可用性不保證，網路、速率限制和附件不適用皆如實回報。
- **風險模式：** 跳過部分額外確認會增加資料遺失及桌面中斷風險，核心保護仍保留，模式不儲存或匯出。

## 一起完善舊系統支援

提交 [Issue](https://github.com/KangQiovo/ProcessKeeper/issues/new/choose) 時請附系統版本/組建/SP、x86/x64/ARM64、Framework、記憶體/顯示卡、DPI、主題、應用程式版本/建置時間及重現步驟。移除路徑、帳戶和權杖，截圖保留錯誤及相關控制項。

推薦驗證冷啟動、取消 UAC、缺 Framework 的復原流程、高 DPI、小螢幕、大清單，以及**僅針對自行建立測試項目**的可還原啟動修改。不要透過結束 Windows 關鍵程序測試。環境驗證建議使用快照虛擬機器或獨立測試機。

上游依據：[WinUI 3](https://learn.microsoft.com/en-us/windows/apps/winui/winui3/)、[Framework 系統需求](https://learn.microsoft.com/en-us/dotnet/framework/get-started/system-requirements)、[Windows 對應版本](https://learn.microsoft.com/en-us/dotnet/framework/install/on-windows-and-server)、[WPF 繪製層級](https://learn.microsoft.com/en-us/dotnet/desktop/wpf/advanced/graphics-rendering-tiers)、[WPF UI](https://github.com/lepoco/wpfui)。上游需求不等於本應用程式完整流程認證。
