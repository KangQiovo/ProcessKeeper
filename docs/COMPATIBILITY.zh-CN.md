# 兼容性与已知限制

## 运行路线

| 环境 | 界面 | 依赖 |
| --- | --- | --- |
| Windows 10 19041+ x64 / Windows 11 x64 | WinUI 3、.NET 8 | x64 包内置运行时 |
| Windows 10 19041+ ARM64 / Windows 11 ARM64 | 原生 ARM64 WinUI 3、.NET 8 | 内置运行时；x86 启动器使用 Windows 模拟 |
| Windows 7 SP1 x86/x64、Windows 8.1 x86/x64、较早或 x86 Win10 | x86 WPF / WPF UI | Framework 4.6.2 或适用的较新 4.x |
| 无 SP1 的 Win7、最初版 Win8、XP、Vista、ARM32 | 仅系统要求页 | 无受支持的管理路线 |

原生引导程序兼容 x86 / Win7 并使用静态 C/C++ 运行库。Win7 兼容包支持 x86、x64；Win10 x86/x64 包同时内置现代 x64 与兼容载荷，x86 使用 WPF，符合条件的 x64 使用 WinUI。ARM64 提供独立原生 WinUI 包；合包包含全部三种路线。三种版本均另有带卸载器的安装版。缺少组件时提供官方下载或帮助网页，不自动执行安装。

这张表是实现目标。**本项目尚未在真实设备或虚拟机上验证 Windows 7、8.1、10 或 ARM64 设备。** 已有 x86 执行测试在现代 Windows 主机进行；未建立最低内存、显卡和旧 CPU 性能承诺。

ARM64 系统选择原生 ARM64 现代载荷，不提供 x86 兼容界面回退。ARM64 禁用仅适用于 x64 的 AVD 环境读取器。交叉编译及在 x64 上运行路线测试不能替代 ARM 设备验证。

**1.6.x 应用内升级请选择 ProcessKeeper-v1.7.1.exe（合包）。** 旧更新器支持 PK14，会安全拒绝 PK17 分包或安装器。若要切换较小版本或安装版，请手动下载对应文件。1.7.1 起默认匹配已验证的包类型及免安装、安装方式；切换其他兼容版本需确认。安装包经过明确同意后打开标准安装向导。

## 两套界面的差异

| 能力 | 现代 | 兼容 |
| --- | --- | --- |
| 进程身份、白名单、关闭确认 | 共用核心 | 共用核心，显式适配 BCL/原生 API |
| 传统安装软件、自启动来源 | 权限允许时可用 | 权限允许时可用 |
| WinRT 应用包及启动声明 | 支持可读取的部分 | 未实现 |
| 无头浏览器实时预览 | 支持已核实的场景 | 未实现 |
| x64 AVD 启动环境还原 | 支持已核实的场景 | x86 模式禁用；可尝试恢复已有图形窗口 |
| 云母/亚克力及动画 | 系统支持时可配置 | 不透明 WPF 主题，效果可能不同 |
| 规则和设置格式 | 共用 | 共用 |

兼容界面是 WPF，**不是在 Win7 上运行 WinUI 3**。字体、主题、DPI 取整、图形加速和滚动可能不同，WPF 可能采用软件绘制。缺少关键身份或能力时应安全拒绝，不能静默跳过保护。

部分虚拟机及托盘适配也依赖可信的跨架构参数/环境读取。x86 兼容进程无法核实 x64 目标时会拒绝这些路线；已有窗口恢复仍可能可用。

## 已知限制及待验证场景

- **实际部署：** 生产 UAC 授权/取消、首次受保护 ProgramData 解包、真实公开版本升级，尚未完整验证用户流程。隔离夹具不能代替。
- **未签名：** Windows 可能提示未知发布者，未包含正式代码签名证书。内部哈希无法认证被任意重写的 EXE。
- **旧系统网络：** 证书、TLS 和系统补丁影响 GitHub 访问，程序不会为绕过失败关闭证书验证或改动全机 TLS 配置。
- **系统读取阻塞：** WMI、COM、服务和文件读取可能超过观察超时。虚拟机查询已限制并发；卡住的提供程序可能持续忙碌，直到返回或应用退出，并非所有原生调用都可取消。
- **目录不完整：** 无法读取的进程、未加载的用户注册表、特殊绿色软件和第三方启动机制可能缺失；启动条目不能证明它启动了当前进程。
- **游戏分组与发布者：** 支持 Steam ACF/VDF、Epic `.item`、育碧安装记录及部分 EA Games 注册表登记；缺失、冲突或不支持的记录保持独立，不保证完整覆盖 EA app 游戏库。微软签名核实设有并发、时间及缓存上限，无法核实或仍在等待的应用保留显示。
- **自启动修改：** 系统/策略/驱动、未知审批格式及缺少可信原启动类型的服务保持只读。损坏备份被拒绝，其余有效备份仍可查看。
- **外部软件适配：** Steam 保存/同步、真实 AVD 重启、虚拟机控制台与托盘唤起依赖外部软件；不宣称已成功重启用户真实 AVD，也不保证云存档完成。
- **窗口恢复：** 后台程序可能没有图形窗口。终端、短暂辅助窗口及 AVD 内部窗口不算恢复成功，窗口显示后也可能无法获取焦点。
- **应用卸载：** 仅覆盖可读取的传统卸载登记，不保证完整发现绿色软件或 Store 应用；静默操作必须有已登记原生命令。登记仍存在时不会报告卸载完成，有自我保护的软件可能需要厂商专用处理工具。
- **性能显示：** 应用内显示界面回调帧率、应用内存与总物理内存；桌面显示整机 CPU、物理内存与观察到的桌面合成帧率，后者不是游戏 FPS 或屏幕刷新率。无法测量时显示未知。亚克力可用性及旧显卡性能存在差异，见[杂项说明](UTILITIES.zh-CN.md)。
- **设置：** 普通失败可尝试回滚，但突然断电无法保证多文件原子性；导入中断后请检查备份。
- **更新：** 没有发行版或官方 SHA-256 时不自动安装。第三方入口可用性不保证，网络、限流和附件不适用均如实报告。
- **风险模式：** 跳过部分额外确认会增加数据丢失及桌面中断风险，核心保护仍保留，模式不保存也不导出。

## 一起完善旧系统支持

提交 [Issue](https://github.com/KangQiovo/ProcessKeeper/issues/new/choose) 时请附系统版本/构建/SP、x86/x64/ARM64、Framework、内存/显卡、DPI、主题、应用版本/构建时间及复现步骤。删除路径、账户和令牌，截图保留错误及相关控件。

推荐验证冷启动、取消 UAC、缺 Framework 恢复、高 DPI、小屏、大列表，以及**仅针对自建测试项目**的可恢复自启动修改。不要通过结束 Windows 关键进程测试。环境验证建议使用快照虚拟机或独立测试机。

上游依据：[WinUI 3](https://learn.microsoft.com/en-us/windows/apps/winui/winui3/)、[Framework 系统要求](https://learn.microsoft.com/en-us/dotnet/framework/get-started/system-requirements)、[Windows 对应版本](https://learn.microsoft.com/en-us/dotnet/framework/install/on-windows-and-server)、[WPF 绘制层级](https://learn.microsoft.com/en-us/dotnet/desktop/wpf/advanced/graphics-rendering-tiers)、[WPF UI](https://github.com/lepoco/wpfui)。上游要求不等于本应用全流程认证。
