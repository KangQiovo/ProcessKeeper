# Process Keeper 1.7.1v2

[English](RELEASE-1.7.2.md) | [简体中文](RELEASE-1.7.2.zh-CN.md) | **繁體中文** | [首頁](../README.zh-TW.md)

發佈名稱為 **1.7.1v2**，內部標準版本號為 **1.7.2**，GitHub 標籤為 `v1.7.2`。原有 1.7.1 更新器要求標準 SemVer，因此採用此數字版本，讓舊版能夠識別更新並維持套件驗證規則。

## 變更

- 自動模式優先透過 GitHub 官方來源下載；官方無法完成有效下載時才嘗試第三方來源，使用者明確選擇仍有效。版本資訊和 SHA-256 依據始終來自固定官方儲存庫。
- 預設在主應用程式顯示下載狀態，不彈出獨立進度視窗。勾選顯示視窗或主動查看時才開啟「更新器」；暫停、繼續和切換來源保留下載狀態。
- 已完成的下載進度旁新增原生「更新並重新啟動」按鈕，僅通過驗證且準備好的下載可用。點擊仍需確認及安全交接；下載完成不會自動結束或安裝。
- 進度視窗改名為「更新器」，使用應用程式書籤加上下載箭頭的獨立圖示；現代版、相容版與可信背景更新助手一致。
- 關於頁將版本名稱與實際建置雜湊分成兩行，雜湊可複製並自動換行。現代版與相容版左下角統一顯示 **1.7.1v2**，套件驗證及更新比較仍使用數字版本 **1.7.2**。在引用專案上方以相同樣式新增本專案網址，開啟瀏覽器前仍需確認。
- 外觀新增可選的原生材質參數：色調不透明度、亮度層不透明度和色調顏色，可即時預覽、恢復原生預設，並納入設定備份。參數只影響背景；雲母取樣桌布，並非透視後方視窗。系統透明度、高對比及材質支援可能限制效果，相容介面保留參數但不能呈現 WinUI 材質。
- 修復自訂材質主題配色未同步及亮背景導致文字難以辨識的問題。統一的 WinUI 主題背景層保護標題、導覽與頁面內容的可讀性，保留已儲存的顏色及透明度參數；外觀面板使用原生控制項背景，移除局部不透明黑塊。
- 保留 1.7.1 的清單展開、微軟應用程式篩選、套件匹配、快取清理及保守的空安裝目錄清理。[上一版改動](RELEASE-1.7.1.zh-TW.md)。

- 修復主視窗首次顯示時，Windows Shell 的短暫遮蔽導致過早回報還原失敗的問題。仍須實際觀察到視窗可見且解除遮蔽才判成功，繼續核驗處理程序身分、桌面以及命令列和輔助頁面。

## 更新及仍存在的限制

舊版外觀設定和備份會遷移到原生預設。包含新增外觀參數的備份需要本次修訂或更新版本；舊版不支援外觀格式版本 2。

持續支援下載進度、暫停、繼續與切換來源。**不倒數自動更新，也不突然退出應用程式**：僅使用者點選更新並確認後才安裝。選取安裝套件後，經驗證與退出交接開啟標準安裝精靈，請確認安裝位置並完成精靈；取消安裝不算更新完成，也不是靜默安裝。舊 1.6.x 更新程式支援 PK14 整合包；PK17 分包需新版更新程式或手動下載。

安裝目錄內使用免安裝包更新，仍更新該安裝目錄並保留原解除安裝登記；若想要獨立的免安裝副本，請另外手動下載到其他目錄。切換受支援的安裝版本還需在安裝精靈確認。合包即使放入已驗證的安裝目錄，也保持預設更新合包。

軟體未簽署，UAC 可能顯示未知發行者。相容介面的材質及部分能力與 WinUI 不同。Windows 7、ARM64 尚未經真實硬體認證；套件校驗與隔離的原生、x86 介面測試不能代表完整的實機安裝、更新驗證。安全軟體、檔案占用及網路異常仍可能中斷操作，程式如實回報，不會誤判成功。歡迎[提交 Issue](https://github.com/KangQiovo/ProcessKeeper/issues)，附版本類型、系統及重現步驟共同改善。
