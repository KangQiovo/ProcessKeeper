# 雜項

[English](UTILITIES.md) | [简体中文](UTILITIES.zh-CN.md) | **繁體中文** | [首頁](../README.zh-TW.md)

雜項頁包含記憶體最佳化、下載器與效能顯示。功能獨立實作，不包含 PCL 原始碼、執行檔或私有模組。

## 記憶體最佳化

研究時以唯讀方式檢查使用者提供的本機 PCL 組件，沒有載入或執行。目錄雖名為 `PCL 正式版 2.10.0`，組件版本實際為 `2.12.7.3`，SHA256 為 `09F7467C5A52D06BBDF3A4EC5F2C4E3298E8031063FF368EB2203B2C10AAAB86`。

`--memory` 啟動分支進入 `MemoryOptimizeInternal`，檢查系統管理員權限、取得 `SeProfileSingleProcessPrivilege`，再向 `NtSetSystemInformation` 資訊類 **80** 依序提交記憶體列表命令 **2、3、4**，處理範圍是整台電腦。

標準模式依序處理工作集、修改頁寫回與待命頁。深度模式另外嘗試檔案快取、低優先待命頁、登錄快取與相同記憶體頁合併。參考了 [PCL Community 歷史實作](https://github.com/PCL-Community/PCL-CE/blob/7b5c912ffa29ef5554d069e7605d3faa99238c4a/PCL.Core/App/Tools/MemSwapWorks.cs) 與 Windows 宣告；檔案快取使用 [Microsoft 公開介面](https://learn.microsoft.com/en-us/windows/win32/api/memoryapi/nf-memoryapi-setsystemfilecachesize)。

執行前需確認，**白名單不豁免**。可能短暫停頓、增加磁碟讀取；工作集變小不代表認可記憶體減少，使用量也可能回升。不會自動定時執行。各步驟回報真實結果，權限不足或不支援不算成功。取消只停止後續步驟，不能撤銷已開始的核心操作。獨立工作執行緒使用暫時執行緒權杖，不修改處理序主要權杖。

報告保留操作前後的可用及總實體記憶體和負向變化；其他程式活動也會影響結果。開發驗證使用模擬後端檢查確認、取消、並行與資源釋放，**未實機執行整機記憶體清理**。Windows 7 與 ARM64 真機仍待驗證，交叉編譯不代表未公開介面已相容。

## 下載器

研究了 [PCL 公開下載引擎](https://github.com/Meloong-Git/PCL/blob/main/Plain%20Craft%20Launcher%202/Modules/Base/ModNet.vb) 的 HTTP 分段、並行、重試、降級與合併檢查。本應用使用固定分段及有界連線，沒有複製其動態拆分排程。

- 支援 HTTP/HTTPS 檔案直連及公開 GitHub 發行、原始檔案連結；一般 GitHub 檔案頁會轉為原始連結。
- 點擊唯讀路徑框旁的資料夾按鈕選擇儲存目錄，無需手寫路徑；另有開啟所選目錄的快捷按鈕。
- 從一個分段開始，動態拆分最大的未完成部分，將尾部交給新連線；閒置連線可以接手較慢的剩餘段。最大連線數可選 1–32，預設 16，並非固定平均切分。普通 HTTP/HTTPS 直連，包括帶查詢參數的連結，都可使用引擎，不需要 GitHub 鏡像。
- 首次並行需要已知長度及實際分段支援；沒有強驗證標記的伺服器仍可首次並行，但重新開始或暫停繼續會捨棄舊片段重下。強 ETag，或沒有 ETag 時符合條件的 Date/Last-Modified，可驗證後續傳；弱 ETag 不會作為 If-Range。沒有可信 SHA256 時，自行計算雜湊不能證明無驗證標記的各段來自同一份未改變檔案。
- GitHub 鏡像放在下載選項中。自動鏡像模式在背景探測，選擇最低延遲的有效來源，失敗時嘗試其他來源。第三方鏡像先確認，只支援不帶查詢參數的公開 GitHub 發布檔案及原始檔案；這項限制不影響普通直連引擎。
- 暫存分段保存在目的地。已驗證的工作階段續傳保留動態分段邊界；URL、長度或驗證標記改變時捨棄舊片段，不混入舊內容。不提供退出後的續傳佇列。
- 檢查分段位置、長度與衝突標記；中斷可重試，不再支援分段時改用單連線。
- 最多跟隨 10 次重新導向，每次連線前檢查目的地；拒絕 HTTPS 降級為 HTTP、無效協定及內嵌帳號密碼的連結。
- 顯示位元組、速度、來源、實際連線與分段數及兩位小數進度。退回單連線時說明原因，驗證完成才顯示 `100.00%`。未知長度顯示已下載量。
- 一律計算 SHA256，可信發布者提供的選填雜湊必須符合才保存。自行計算雜湊不能證明可信度。
- 不覆寫現有目的檔案，不自動執行下載內容。取消或退出嘗試清理未完成片段，保留已完成檔案；暫存檔案被鎖定時如實提示稍後清理，避免頁面崩潰。

動態排程器為獨立實作，沒有複製 PCL 原始碼。不繞過登入或存取限制，不匯入瀏覽器 Cookie，不提供種子下載。增加連線不能繞過伺服器總限速，也無法保證所有連結跑滿頻寬；HTTP 錯誤、驗證失敗及來源無法連線都如實顯示。

## 效能顯示

應用內顯示應用繪製速率、使用量及總實體記憶體，限制在內容區域。桌面懸浮窗顯示整機 CPU、實體記憶體及實際觀察到的桌面合成速率，不等於遊戲 FPS 或螢幕更新率。靜止桌面可能很低，無法測得時不偽造數值。

可調整配置、材質、位置、大小與鎖定。目前 Windows 主機的原生測試涵蓋拖曳不移動主視窗、邊界、圓角、明暗模式及關閉清理。舊系統可能不支援壓克力或合成速率測量。
