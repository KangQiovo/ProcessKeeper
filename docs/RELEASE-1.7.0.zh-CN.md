# Process Keeper 1.7.0

[English](RELEASE-1.7.0.md) | **简体中文** | [繁體中文](RELEASE-1.7.0.zh-TW.md) | [首页](../README.zh-CN.md)

## 选择免安装包

1.7.0 发布**七个包**：三个免安装版本、三个对应的带卸载器安装版本，以及一个免安装合包。

| 文件 | 适用环境 |
| --- | --- |
| `ProcessKeeper-v1.7.0-win7-x86-compat.exe` | 免安装 \| Win7 SP1 / 8.1 及受支持的新系统 x86/x64 \| WPF；需要 .NET Framework 4.6.2 或兼容的较新 4.x。 |
| `ProcessKeeper-v1.7.0-win10-x86-x64.exe` | 免安装 \| Win10/11 x86、x64 \| x64 19041+ 使用 WinUI；内置 WPF 兼容界面供 x86 或受支持的较早 x64 系统使用。 |
| `ProcessKeeper-v1.7.0-win10-arm64.exe` | 免安装 \| Win10 19041+ / Win11 ARM64 \| 原生 ARM64 WinUI；x86 引导器通过模拟运行。 |
| `ProcessKeeper-v1.7.0-win7-x86-compat-setup.exe` | 安装版 + 卸载器 \| Win7 SP1 / 8.1 及受支持新系统 x86/x64。 |
| `ProcessKeeper-v1.7.0-win10-x86-x64-setup.exe` | 安装版 + 卸载器 \| Win10/11 x86、x64 \| 包含相同的现代与兼容路线。 |
| `ProcessKeeper-v1.7.0-win10-arm64-setup.exe` | 安装版 + 卸载器 \| Win10 19041+ / Win11 ARM64。 |
| `ProcessKeeper-v1.7.0.exe` | 免安装合包 \| 包含全部三种运行载荷 \| 下载最大；保留旧更新器支持的 PK14 格式。 |

原生引导程序兼容 x86 / Win7 并使用静态 C/C++ 运行库。Win7 兼容包支持 x86、x64；Win10 x86/x64 包同时内置现代 x64 与兼容载荷，x86 使用 WPF，符合条件的 x64 使用 WinUI。ARM64 提供独立原生 WinUI 包；合包包含全部三种路线。三种版本均另有带卸载器的安装版。缺少组件时提供官方下载或帮助网页，不自动执行安装。

## 从 1.6.x 升级

**1.6.x 应用内升级请选择 ProcessKeeper-v1.7.0.exe（合包）。** 旧更新器支持 PK14，会安全拒绝 PK17 分包或安装器。若要切换较小版本或安装版，请手动下载对应文件。1.7.0 起更新匹配原包类型，安装器不会交给自动更新助手执行。

运行适合的新 EXE 并确认管理员授权。本机白名单配置和设置独立于下载包保存，会继续可用；关闭应用前请复核规则。首次安装仍以**空白本地白名单**开始，七应用社区模板仅在用户主动获取云端配置时加载。

## 同一应用合并为可展开的主项

- 已安装应用根据可执行文件、身份及产品/发布者信息合并重复登记和多个版本；原始安装记录、位置、主程序/卸载标签及不同组件路径均保留可查。
- 自启动将同一应用的多个来源放在一个主项下；每个注册表视图、任务及其他支持的入口仍保留准确目标、启用状态和独立管理操作。
- 运行中程序和白名单共用归属规则；卸载分组规范化版本、架构后缀，同时保留每个独立卸载登记。
- 选择主项会包含已知的全部子项，包括折叠内容；部分选中、搜索及刷新保留准确成员，不修改白名单保护或启用状态。

未知归属或发布者冲突仍独立显示。分组只整理界面，不授权按名称启动、关闭、禁用或卸载；文件名匹配及推断的主程序标签仍可能有误。

## 应用更新

更新弹窗显示实际 Markdown 日志和发行附件。1.7.0 及以后自动安装按当前包类型和架构选择适用附件。下载进度窗支持暂停、继续和切换源，同次应用运行中切换页面或重复检查不会丢失下载；不保证关闭应用后恢复。

下载完成后保持待更新；用户点击更新并重新启动并确认后才退出，没有自动倒计时。替换文件和更新桌面快捷方式使用校验后的交接。新应用报告就绪后才移除本次替换的旧包备份，不清理无关 EXE。缺少摘要、附件不兼容及网络错误会如实显示。

## 验证与待完善内容

当前现代 Windows 主机上的隔离原生 WinUI 和 32 位 WPF 夹具已检查分组，覆盖英文、简中、繁中、深浅主题及两种窗口宽度。只读安装/启动清单检查确认保留了原始可执行文件路径和入口身份；这些检查未关闭用户进程或修改用户自启动配置。

**Win7 / 8.1 / 10 及 ARM64 真机或虚拟机部署仍未验证。** 交叉编译和现代主机上的 32 位 CLR 测试不能替代这些环境实测。兼容路线仍缺少 WinRT 应用包清单/启动声明、无界面浏览器实时预览及 x64 AVD 环境还原；ARM64 也禁用该 x64 专用 AVD 读取器。字体、材质、图形及旧硬件性能可能不同，正式 UAC、首次缓存解包及公开版本升级流程仍待现场验证。详见[兼容性与限制](COMPATIBILITY.zh-CN.md)。

欢迎提交可复现的 [Issue](https://github.com/KangQiovo/ProcessKeeper/issues/new/choose)，附系统/构建号、架构、主题/DPI、应用版本及脱敏步骤。也欢迎共创[通用云端配置](CLOUD-PROFILES.zh-CN.md)、翻译与兼容修复；请勿提交个人路径、凭据、测试包或含隐私的日志。

## 安装与卸载

安装器使用固定 NSIS 3.13 编译并索要管理员权限，登记受本项目管理的计算机级程序项，安装固定文件名 ProcessKeeper.exe、Uninstall.exe、install.ini，并创建对应快捷方式。卸载器只删除所属的应用文件、快捷方式及登记；保留设置、历史和自启动恢复备份。README 说明了可选的本用户数据手动清理。Win7、x86 及 ARM64 目标系统上的真实安装和卸载仍待验证。

在**设置 → 关于 → 本机文件**中使用**清理应用缓存**，清理已验证的旧版本缓存。当前版本、占用中的文件、下载、白名单配置和设置保留；不递归删除未经确认或已修改的目录。结果显示实际文件数、大小和保留的缓存组数。
