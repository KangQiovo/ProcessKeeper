杂项页包含内存优化、下载器和性能显示。功能独立实现，不包含 PCL 源码、可执行文件或私有模块。

## 内存优化

研究中以只读方式检查了用户提供的本地 PCL 程序集，没有加载或执行它。目录虽名为 `PCL 正式版 2.10.0`，程序集版本实际为 `2.12.7.3`。SHA256 为 `09F7467C5A52D06BBDF3A4EC5F2C4E3298E8031063FF368EB2203B2C10AAAB86`。

`--memory` 启动分支进入 `MemoryOptimizeInternal`，检查管理员权限、取得 `SeProfileSingleProcessPrivilege`，再向 `NtSetSystemInformation` 的信息类 **80** 依次提交内存列表命令 **2、3、4**。它处理的是整机内存，不仅是启动器或 Minecraft。

本应用的标准模式按上述三步处理工作集、修改页写回与待机页。深度模式额外尝试文件缓存、低优先级待机页、注册表缓存与相同内存页合并。参考了 [PCL Community 历史实现](https://github.com/PCL-Community/PCL-CE/blob/7b5c912ffa29ef5554d069e7605d3faa99238c4a/PCL.Core/App/Tools/MemSwapWorks.cs) 与 Windows 声明；文件缓存步骤使用 [微软公开的接口](https://learn.microsoft.com/en-us/windows/win32/api/memoryapi/nf-memoryapi-setsystemfilecachesize)。

执行前会说明所选范围并要求确认，**白名单不豁免**。可能短暂卡顿、增加磁盘读取；工作集变小不代表已提交内存减少，占用也可能回升。不会自动定时执行。各步骤显示真实结果，不支持或权限不足不会算作成功。取消只停止后续步骤，不能撤销已经开始的内核操作。独立工作线程使用临时线程令牌，不修改进程主令牌。

报告显示操作前后的可用及总物理内存，负向变化也如实保留；其他程序活动会影响结果。开发验证使用模拟后端检查确认、取消、并发和资源释放，**未实机执行整机内存清理**。Windows 7 和 ARM64 真机仍待验证，交叉编译不等于未公开接口已兼容。

## 下载器

研究了 [PCL 公开下载引擎](https://github.com/Meloong-Git/PCL/blob/main/Plain%20Craft%20Launcher%202/Modules/Base/ModNet.vb) 的 HTTP 分段、并行、重试、降级及合并校验机制。本应用使用固定分段和有界并发，未复制其动态拆分调度器。

- 支持 HTTP/HTTPS 文件直链及公开 GitHub 发布、原始文件链接；普通 GitHub 文件页面会转为原始链接。
- 点击只读路径框旁的文件夹按钮选择保存目录，无需手写路径；另有打开所选目录的快捷按钮。
- 从一个分段开始，按最大未完成部分动态拆分，将末尾交给新增连接；空闲连接可以接力较慢的剩余段。最大连接数可选 1–32，默认 16，并非固定平均切分。普通 HTTP/HTTPS 直链，包括带查询参数的直链，都可以使用这套引擎，无须 GitHub 镜像。
- 首次并发下载需要已知文件长度及实际分段支持；缺少强校验标记的服务器仍可进行首次分段下载，但重新开始或暂停继续时会丢弃旧片段重下。强 ETag 或没有 ETag 时满足要求的 Date/Last-Modified 允许校验后续传，不会把弱 ETag 发送为 If-Range。未提供可信 SHA256 时，自行计算哈希无法证明无校验标记的各段来自同一份未变化文件。
- GitHub 镜像放在下载选项中。自动镜像模式后台探测并选择最低延迟的有效源，失败时尝试其他源。第三方镜像先确认，只支持不带查询参数的公开 GitHub 发布文件及原始文件；该限制不影响普通直链引擎。
- 临时分段保存在目标目录中。已校验的当前会话续传保留动态分段边界；URL、长度或校验标记变化时丢弃旧片段，不混入旧内容。不提供退出应用后的续传队列。
- 检查分段位置、长度与冲突校验标记；中断可重试，服务器不再支持分段时退回单连接。
- 最多跟随 10 次重定向，每次连接前检查目标；拒绝 HTTPS 降级为 HTTP、无效协议及内嵌账号密码的链接。
- 显示字节数、速度、来源、实际连接数和分段数及两位小数进度，退回单连接时说明原因，校验完成才显示 `100.00%`。未知长度显示已下载字节。
- 始终计算 SHA256，可填写可信发布者给出的哈希，匹配后才保存最终文件。仅自行计算哈希不代表文件可信。
- 不覆盖已有目标，不自动运行下载文件。取消或退出尝试清理未完成片段，已完成文件保留；临时文件被锁定时如实提示稍后清理，避免页面闪退。

动态调度器为独立实现，没有复制 PCL 源码。不绕过登录、权限或访问限制，不导入浏览器 Cookie，也不提供种子下载。增加连接无法绕过服务器总限速，也不能保证所有链接跑满带宽；HTTP 错误、校验失败和源不可用均如实显示。

## 性能显示

应用内显示应用渲染速率、占用及总物理内存，限制在内容区域。桌面悬浮窗显示整机 CPU、物理内存与实际观察到的桌面合成速率，后者不是游戏 FPS 或屏幕刷新率。静止桌面可能很低，无法取得时不伪造数值。

可调整布局、材质、位置、大小和锁定。当前 Windows 主机的原生窗口测试包含拖动不带动主窗口、边界、圆角、明暗模式和关闭清理。旧系统可能不支持亚克力或合成速率测量。
