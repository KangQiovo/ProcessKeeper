## 變更

- 點選應用程式列、圖示或文字展開或摺疊詳情，僅點選核取方塊才選取項目。涵蓋現代版與相容版的全部清單，以及平台、可執行檔、處理程序、自動啟動、解除安裝等巢狀項目。選取主項同時選取已知子項，摺疊時也有效。現有保留、啟用功能不變；取消或操作失敗保留原選取狀態。
- 修正選取**隱藏 Microsoft 應用程式**後仍顯示商店版小畫家的問題。必須核實系統登記的健康 Microsoft Store/System 套件及實際安裝路徑；不能僅憑同名檔案、顯示的發行者或複製的 EXE 判定 Microsoft 身分。
- 更新對話框依目前套件類型與已驗證的執行方式預設選取：整合包對應整合包，分包保持對應系統與架構，安裝版優先對應安裝套件。缺少符合的附件時要求使用者明確選擇，不會自行切換。手動改用其他相容套件需額外確認；不相容或無法驗證的附件仍不可安裝。
- 側欄顯示正在執行的版本號；關於頁在版本後顯示配合佈景主題的整合包、免安裝、安裝或相容類型標籤。移除更新來源上方的固定儲存庫文字，內部官方儲存庫保持固定。
- 快取清理增加應用程式管理目錄內閒置的完整更新套件、未完成下載及更新準備目錄。保留使用中的工作階段、鎖定或無法核實的檔案、設定與白名單；不掃描使用者任意下載目錄。
- 擴充編號 `unins` 檔案、本地化名稱及廠商變體等解除安裝程式識別。仍以登記的解除安裝命令為執行依據，包括合法的 `Setup.exe`、`Update.exe` 入口；名稱推斷只提供不確定的標籤，不會據此猜測執行命令。
- 註冊解除安裝成功後，只清理經核實為空的對應安裝目錄。要求完整清單、原註冊項已移除、無共享歸屬且目錄身分未變化。非空、共享、被替換、連結或無法驗證的目錄及全部上層目錄均保留，不遞迴刪除殘留檔案。

## 更新及仍存在的限制

持續支援下載進度、暫停、繼續與切換來源。**不倒數自動更新，也不突然退出應用程式**：僅使用者點選更新並確認後才安裝。選取安裝套件後，經驗證與退出交接開啟標準安裝精靈，請確認安裝位置並完成精靈；取消安裝不算更新完成，也不是靜默安裝。舊 1.6.x 更新程式支援 PK14 整合包；PK17 分包需新版更新程式或手動下載。

安裝目錄內使用免安裝包更新，仍更新該安裝目錄並保留原解除安裝登記；若想要獨立的免安裝副本，請另外手動下載到其他目錄。切換受支援的安裝版本還需在安裝精靈確認。合包即使放入已驗證的安裝目錄，也保持預設更新合包。

軟體未簽署，UAC 可能顯示未知發行者。相容介面的材質及部分能力與 WinUI 不同。Windows 7、ARM64 尚未經真實硬體認證；套件校驗與隔離的原生、x86 介面測試不能代表完整的實機安裝、更新驗證。安全軟體、檔案占用及網路異常仍可能中斷操作，程式如實回報，不會誤判成功。歡迎[提交 Issue](https://github.com/KangQiovo/ProcessKeeper/issues)，附版本類型、系統及重現步驟共同改善。
