# 雲端白名單共創目錄

[English](README.md) | [简体中文](README.zh-CN.md) | **繁體中文**

便攜的單套白名單 JSON 檔案直接放在本目錄。所有使用者皆可透過 Fork 和 Pull Request 提交新設定，由維護者審核合併。請先閱讀[格式、限制與共創流程](../../docs/CLOUD-PROFILES.zh-TW.md)。

`kangqi-default.json` 是包含七個應用程式的可選範本。首次本機白名單仍為空；應用程式只在使用者主動取得後讀取雲端，預覽並確認後才匯入。匯入計入最多五套本機設定。

不要提交私人路徑、本機設定、憑據、符號連結、子目錄或可執行內容。共創規則只是比對條件，在其他電腦上可能需要調整。
