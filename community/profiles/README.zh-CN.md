# 云端白名单共创目录

[English](README.md) | **简体中文** | [繁體中文](README.zh-TW.md)

便携的单套白名单 JSON 文件直接放在本目录。所有用户均可通过 Fork 和 Pull Request 提交新配置，由维护者审核合并。请先阅读[格式、限制与共创流程](../../docs/CLOUD-PROFILES.zh-CN.md)。

`kangqi-default.json` 是包含七个应用的可选模板。首次本地白名单仍为空；应用只在用户主动获取后读取云端，预览并确认后才导入。导入计入最多五套本地配置。

不要提交私人路径、本地设置、凭据、符号链接、子目录或可执行内容。共创规则只是匹配条件，在其他电脑上可能需要调整。
