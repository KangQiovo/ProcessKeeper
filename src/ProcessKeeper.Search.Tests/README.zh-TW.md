# 搜尋關聯測試夾具

[English](README.md) | [简体中文](README.zh-CN.md) | **繁體中文**

僅使用合成中繼資料，不掃描檔案系統，不擷取或控制真實處理程序，不寫入使用者設定，也不建立視窗。

使用所需 .NET SDK，從儲存庫根目錄執行：

```powershell
dotnet run --project src/ProcessKeeper.Search.Tests/ProcessKeeper.Search.Tests.csproj -c Release
```

## 涵蓋範圍

- 公開處理程序欄位、精確 PID 比對、大小寫處理和不同地區設定。
- 子處理程序命中後保留所屬應用程式。
- 白名單搜尋使用呼叫端提供的可見處理程序範圍；停用規則仍可檢視，但不改變保護狀態。
- 已安裝應用程式及可執行元件透過應用程式鍵、完整路徑、處理程序檔名和目錄邊界關聯規則。
- 同名不同路徑、缺失或獨立元件鍵、離線軟體及缺失中繼資料。
- 大規模合成軟體目錄和規則集上的並行查詢隔離。

以真實結束狀態和斷言摘要為準，不依賴固定預期數量。這些測試不能取代介面互動、清單虛擬化、實際掃描延遲或記憶體測量，請參閱[測試指南](../../docs/TESTING.zh-TW.md)。
