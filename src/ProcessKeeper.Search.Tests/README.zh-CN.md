# 搜索关联夹具

[English](README.md) | **简体中文** | [繁體中文](README.zh-TW.md)

仅使用合成元数据，不扫描文件系统，不采集或控制真实进程，不写用户设置，也不创建窗口。

使用所需 .NET SDK，从仓库根目录执行：

```powershell
dotnet run --project src/ProcessKeeper.Search.Tests/ProcessKeeper.Search.Tests.csproj -c Release
```

## 覆盖范围

- 公共进程字段、精确 PID 匹配、大小写处理和不同区域设置。
- 子进程命中后保留所属应用。
- 白名单搜索使用调用方提供的可见进程范围；停用规则仍可查看，但不改变保护状态。
- 已安装应用及可执行组件通过应用键、完整路径、进程文件名和目录边界关联规则。
- 同名不同路径、缺失或独立组件键、离线软件及缺失元数据。
- 大规模合成软件目录和规则集上的并发查询隔离。

以真实退出状态和断言摘要为准，不依赖固定预期数量。这些测试不能替代界面交互、列表虚拟化、实际扫描延迟或内存测量，参见[测试指南](../../docs/TESTING.zh-CN.md)。
